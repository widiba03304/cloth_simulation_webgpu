# Archived: Native (C++/WASM) modules

This directory is **archived**. The app does not load or use the WASM module; cloth grid and constraints are built in TypeScript (e.g. in the 2D cloth preview). Kept for reference in case a C++ mesh builder or parser is reintroduced later.

Original build: Emscripten (emcc), see Makefile and CMakeLists.txt. Exported: buildGridClothCounts, buildGridCloth.
