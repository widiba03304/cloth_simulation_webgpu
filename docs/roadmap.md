## Phase 1 — 핵심 워크플로우 완성 ⚡ (가장 시급)

### 1-A. 3D 클로스 시뮬레이션 [**시작됨**]

**목표:** Material Editor의 2D 미리보기를 3D 마네킹 위의 실제 드레이핑으로 전환.

**기술 접근:**
- `src/renderer/sim/cloth3d/` 에 WebGPU compute 기반 3D 시뮬레이터 구현
- Verlet 적분 + 그래프 컬러링 PBD 제약 (2D 미리보기와 동일한 알고리즘, 3D 좌표)
- **캡슐 콜라이더** (capsule colliders)로 마네킹 신체 충돌 처리 (머리/목/상체/하체/팔/다리)
- T-포즈 초기 배치: 패턴을 신체 앞쪽 반원통 형태로 초기화 → 중력 + 충돌로 자연스럽게 드레이핑
- `src/renderer/render/pipeline.ts`에 cloth render pass 추가 (double-sided PBR, IBL 조명)
- `src/renderer/main.ts` 애니메이션 루프에 cloth step + draw 통합

**구현 파일:**
```
src/renderer/sim/cloth3d/
├── cloth3d.ts                  # 메인 클래스 (createCloth3D 팩토리)
├── cloth3d.simParams.wgsl      # 시뮬 파라미터 유니폼 구조체
├── cloth3d.integrate.wgsl      # Verlet 적분 (3D)
├── cloth3d.constraint.wgsl     # PBD 제약 (3D, 그래프 컬러링)
├── cloth3d.normal.wgsl         # 표면 법선 계산 (3D)
└── cloth3d.collide.wgsl        # 캡슐 + 바닥 충돌

src/renderer/render/
├── cloth3d.vert.wgsl           # 클로스 버텍스 셰이더
└── cloth3d.frag.wgsl           # 클로스 프래그먼트 셰이더 (양면 IBL PBR)
```

### 1-B. 패널 기반 패턴 시스템

**목표:** 직사각형 단일 패널에서 전/후면 패널 + 봉합선(seam) 시스템으로 전환.

**데이터 모델 변경:**
```typescript
// 현재
interface PatternAsset { grid: { rows, cols, spacing }; pinned: string; }

// 목표
interface PatternAsset {
  panels: Panel[];    // 각 패널: { id, rows, cols, spacing, pinned, placement3D }
  seams: Seam[];      // { panelA, edgeA, panelB, edgeB } - 봉합할 엣지 쌍
}
```

**구현 내용:**
- 봉합선 제약: seam으로 연결된 엣지 파티클들을 서로 끌어당기는 스프링 제약 추가
- 전/후면 패널: 앞 패널 + 뒤 패널이 어깨와 옆선에서 봉합
- 패턴 에디터 UI에 패널 탭 추가

## Phase 4 — 시뮬레이션 품질 향상

### 4-A. 동적 시뮬레이션

- **걷기 애니메이션** 재생 중 클로스 반응 시뮬레이션 (IK 기반 포즈 변화)
- **바람 효과** 파라미터 (방향, 강도, 난류)
- **포즈 변경 시 리시뮬레이션** (IK 조작 후 실시간 재계산 + 캡슐 업데이트)

### 4-B. 시뮬레이션 품질 컨트롤

- 시뮬레이션 해상도 (Low: 30fps/2substep, Med: 60fps/4substep, High: 60fps/8substep)
- 시뮬레이션 결과 "굳히기(freeze)" — 원하는 드레이프 상태 고정
- Self-collision 활성화/비활성화 (성능 vs 품질)

## Phase 5 — 내보내기 및 협업

### 5-A. 산업 표준 포맷 내보내기

| 포맷 | 용도 |
|---|---|
| **SVG/DXF** | 패턴 파일 (실제 재단용, 플로터 출력) |
| **OBJ/glTF** | 3D 드레이프 메쉬 (다른 3D 툴로 이전) |
| **PDF** | 패턴 인쇄 (A4 타일링 포함) |
| **PNG 시퀀스** | 360도 턴테이블 애니메이션 |

### 5-B. 프리젠테이션 모드

- **턴테이블 뷰** — 자동 360도 회전 렌더링
- **기술 도면 뷰** — 전면/측면/후면 정사영 (garment tech drawing)
- **라이팅 프리셋** — 패션 카탈로그용 스튜디오 조명
